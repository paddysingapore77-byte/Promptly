# PROMPTLY — Free static landing page

This is a standalone HTML landing page. No framework, server, database, or paid hosting is required.

## Edit
Open `index.html` and search for:
- `[Product name]`
- `[PRICE]`
- `[Add persona]`
- `[Insert verified customer quote here.]`
- `[Add your actual delivery/access process here.]`

The 10 products are stored together in the small `products` array near the bottom, making product edits easy.

## Free publishing options
1. GitHub Pages — create a repository, upload `index.html`, then enable Pages.
2. Netlify — use Netlify Drop to drag the folder onto the page.
3. Cloudflare Pages — connect the folder/repository as a static site.

No paid hosting is required for the site itself.
